# דיזיין סיסטם למצגת

תבנית המצגות של anoda: צבעי הדיזיין סיסטם, Google Sans, עברית מימין לשמאל, ואילוסטרציות בסגנון אחד.
התבנית בנויה כ-skill של Claude, כך ש-Claude בונה מצגת חדשה באותו סגנון בלי להתחיל מאפס.

## מה יש כאן

| | |
|---|---|
| `SKILL.md` | כללי העיצוב, כללי העברית וה-RTL, סגנון הכתיבה, ותהליך העבודה (כולל העברה ל-Google Slides) |
| `assets/slides/` | 20 שקופיות לדוגמה: שער, שקופיות מעבר, כרטיסים עם אילוסטרציות, צעדים ממוספרים, שקופית בעיה, Double Diamond, Road map, רשימת משימות ושקופית סיום |
| `assets/deck.example.json` | קובץ האינדקס של מצגת לדוגמה |
| `assets/logo/` | הלוגו בלבן (לשקופיות סגולות) ובצבע (לפוטר) |
| `assets/images/` | אייקון האפליקציה ותמונות הצוות |
| `scripts/rtl.py` | עוטף כל שורה בעברית כך שתוצג נכון מימין לשמאל |

## איך משתמשים

מעתיקים את התיקייה לתיקיית ה-skills של Claude Code:

```bash
cp -R presentation ~/.claude/skills/anoda-deck
```

ואז מבקשים מ-Claude מצגת, למשל: "תכין מצגת לסדנה של anoda על תיק עבודות".
